# My-first-Virtual-Homelab
This is my first time downloading and installing VM for homelab. 
First i downloaded Latest version of VirtualBox for my fedora 44, after i installed it, i also installed VirtualBox Extension Pack for more compatibility.
Once the VirtualBox was set, i downloaded Windows 11 ISO image.
When it downloaded i attached the ISO to my Virtualbox, after i tried to run the VM it gave me error, but i fixed it right away using terminal (with help of AI).

Once it started, it wasn't full screen, so i 'inserted Guest Additions CD image'.
Also the mouse had problem tracking my movement so i fixed it by changing 'Pointing device' from 'USB Tablet' to 'USB multi-Touch TouchScreen and TouchPad' (i think this was problem because of i have TouchScreen laptop, and it didn't adapt with USB tablet.


This was really fun experience!
it wasn't difficult at all, actually it was piece of cake!

my rating of Difficulty is 3.9/10.
This was my first time working with VMs and also with Github.com
